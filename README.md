# Чёрный список

Публичный реестр Telegram ID, заблокированных за нарушения: шаринг подписок, накрутку рефералов, абуз триалок, скам, слив ключей и прочие злоупотребления сервисом.

## Формат

[`blacklist.txt`](blacklist.txt) — по одному ID на строку, отсортировано по возрастанию. Рядом через `#` — причина и, если есть, ссылка на доказательство.

```
777000 # https://t.me/c/.../98424/368656 состоят в группе по сливам подписок
143114631 # Скам
```

## Интеграция

Raw-ссылка для автоматического подтягивания списка:

```
https://raw.githubusercontent.com/remnashop/blacklist/main/blacklist.txt
```

## Как добавить нарушителя

Через [форму заявки](../../issues/new?template=blacklist.yml): числовой Telegram ID, причина и доказательства. Без пруфов заявку не рассматриваем.

Мейнтейнеры вносят одобренные заявки скриптом, который сам ставит ID на нужное место по возрастанию:

```
python3 scripts/add_ban.py <telegram_id> "причина"
```
