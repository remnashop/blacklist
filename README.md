# Чёрный список

Публичный реестр Telegram ID и email, заблокированных за нарушения: шаринг подписок, накрутку рефералов, абуз триалок, скам, слив ключей и прочие злоупотребления сервисом.

## Формат

[`blacklist.txt`](blacklist.txt) — по одной записи на строку: сначала Telegram ID по возрастанию, затем email по алфавиту (в нижнем регистре). Рядом через `#` — причина и, если есть, ссылка на доказательство.

```
777000 # https://t.me/c/.../98424/368656 состоят в группе по сливам подписок
143114631 # Скам
abuser@example.com # Абуз триалки
```

Достаточно одного адреса: регистр и алиасы почтовых сервисов (`+тег`, точки в Gmail, домены-синонимы Gmail, Яндекса и iCloud) remnashop сводит к одному ящику сам.

## Интеграция

Raw-ссылка для автоматического подтягивания списка:

```
https://raw.githubusercontent.com/remnashop/blacklist/main/blacklist.txt
```

## Как добавить нарушителя

Через [форму заявки](../../issues/new?template=blacklist.yml): числовой Telegram ID или email, причина и доказательства. Без пруфов заявку не рассматриваем.

Мейнтейнеры вносят одобренные заявки скриптом, который сам ставит запись на нужное место:

```
python3 scripts/add_ban.py <telegram_id|email> "причина"
```
